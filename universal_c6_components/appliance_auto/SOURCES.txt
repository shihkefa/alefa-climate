This component is a new bounded, single-owner UART implementation, using protocol
mappings from the following upstream sources. It does NOT run the complete upstream
drivers and does not claim all optional features or all appliance models.

https://github.com/tsunglung/taixia

Reference: components/taixia, Hitachi RD-240HH, Panasonic FYTW-08810115 and
Daikin dehumidifier YAML examples. Upstream license: TAIXIA-LICENSE (LGPL-2.1).

Supported basic protocol subset:
TaiSEIA: read registration, SA ID, brand/model, full status; AC writes power,
mode, target temperature, fan; dehumidifier writes only power and fan level.
S21: F1/G1 basic status, FC/GC optional model code, RH/SH optional temperature,
D1 power/mode/temperature/fan. Does not implement P1/P2, S403 without S21 support,
X50A-only protocols, swing/presets, or optional feature negotiation.
